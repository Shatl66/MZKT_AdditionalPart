Добавление доп частей к выделенному на схеме устройству. Физически эти доп компоненты являются атрибутами которые вписываются в "Параметры изделия в проекте".
В дальнейшем, другое наше приложение E3WGM ( https://github.com/andron1989/E3WGM/ ) использует эти данные для вывода полного состава ЭСИ проекта Е3, затем для передачи этого ЭСИ в Windchill, рассчета там позиций спецификации и последующей
передаче номеров этих позиций обратно в проект Е3 и их вывода на полочки в схемах проекта.
